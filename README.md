# Chef's Kitchen – Application Improvements and Updates

## Overview
Chef's Kitchen is a React Native application developed using TypeScript (TSX). The application has been improved from its previous version by introducing a more attractive user interface, improved navigation, and additional dish management features. The main purpose of these changes is to make the application easier to use and to provide better functionality when managing dishes.

## Changes and Improvements Made

The following improvements have been applied to the previous version of the application:

### 1. Improved Splash Screen
- Added a new splash screen with a red background to create a more attractive first impression.
- Added a chef image to represent the Chef's Kitchen application.
- Added the application name, "CHEF'S KITCHEN", and the tagline "Delicious meals, prepared with love."
- Added a loading message to indicate that the application is starting.
- Improved the overall appearance of the application's opening screen.

### 2. New Welcome and Login Screen
- Introduced a welcome screen displaying the Chef's Kitchen logo/image.
- Added a text input field that allows users to enter their names.
- Added a LOGIN button to allow users to proceed into the application.
- Improved the user experience by welcoming users before they access the main dashboard.

### 3. Improved Main Dashboard
- Redesigned the main dashboard with a red header displaying the application name.
- Added a personalised welcome message displaying the user's name after login.
- Improved the layout and organisation of the dish management section.
- Used different colours to make important information easier to identify.

### 4. Added Dish Management Statistics
Three new summary sections were introduced to provide an overview of the available dishes:

- **Total Items:** Displays the total number of dishes currently available.
- **Total Price:** Calculates and displays the combined price of all available dishes.
- **Average Price:** Calculates the average price of the available dishes.

All prices are displayed in South African Rand (R).

### 5. Added Search Functionality
- Introduced a search bar that allows users to search for dishes by name or description.
- Makes it easier to find specific dishes without having to scroll through the entire list.

### 6. Improved Course Filtering
- Added course filtering buttons to organise dishes according to their categories.
- Users can filter dishes using the following categories:
  - All
  - Starter
  - Mains
  - Dessert
- This makes it easier to view dishes belonging to a specific course.

### 7. Added New Dish Functionality
- Introduced an ADD NEW DISH button.
- Allows users to access the dish creation functionality and add new dishes to the application.

### 8. Improved Dish Display
- Improved the appearance of the available dishes section.
- Added food images to make the dish listings more visually appealing.
- Added a dish count to show the number of available dishes.
- Improved the overall presentation and organisation of dish information.

## Benefits of the Improvements

The updates made to Chef's Kitchen provide several benefits:

1. **Better User Experience:** The redesigned screens make the application easier to understand and navigate.
2. **Improved Organisation:** Course filtering allows users to organise and find dishes more easily.
3. **Time Saving:** The search feature helps users locate dishes quickly.
4. **Better Price Management:** The total price and average price calculations provide a quick overview of dish costs.
5. **Personalised Experience:** Users are welcomed using the names they enter during login.
6. **Attractive Design:** The updated colours, images, buttons and layout give the application a more professional appearance.

## Technologies Used

- TypeScript (TSX)
- React Native
- JavaScript
- Visual Studio Code
- Expo (if applicable)

## Conclusion

The updated Chef's Kitchen application introduces significant improvements compared to the previous version. The application now includes a redesigned splash screen, a welcome and login screen, an improved dashboard, dish statistics, search functionality, course filtering and the ability to add new dishes.
